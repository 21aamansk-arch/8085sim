ⓘ Quick guide
Basic workflow
1. Write or load a program.
2. Click Assemble & Reset to check the source.
3. Use Step to execute one instruction or Run to execute until HLT.

Supported core instructions
MVI, MOV, LXI, LDA, STA, LHLD, SHLD, LDAX, STAX, ADD, ADC, SUB, SBB, ADI, SUI, INR, DCR, INX, DCX, DAD, ANA, ORA, XRA, CMP, ANI, ORI, XRI, CPI, JMP, JZ, JNZ, JC, JNC, NOP, HLT, and more basic operations.

Educational simulator: a lightweight subset is implemented in this standalone file; it is not a cycle-accurate hardware emulator.
